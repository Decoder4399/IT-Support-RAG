# Software Installation Guide

## Overview
This guide covers the standard procedure for requesting and installing approved software on company workstations.

## Software Installation Policy
- Only approved software can be installed on company computers
- Software must be compatible with company security standards
- All installations require manager approval
- Personal software is not allowed on company devices

## Requesting Software

### Step 1: Check Approved Software List
Before submitting a request, check if the software is already approved:
- Open the Software Center app on your computer (Windows) or Self Service (Mac)
- Browse available applications
- If listed, you can install directly without IT approval

### Step 2: Submit Installation Request
If software is not in the approved list:
1. Go to https://support.company.com/software-request
2. Fill out the software request form:
   - Software name and version
   - Business justification
   - Department and manager name
   - Number of licenses needed
3. Submit the form
4. IT will review within 3 business days

### Step 3: Approval Process
- Request goes to your manager for approval
- IT Security reviews the software for compatibility
- If approved, IT will install the software remotely
- You'll receive an email notification

## Self-Installation (Approved Software)

### Windows - Using Software Center
1. Open Software Center from Start Menu
2. Browse or search for the application
3. Click "Install"
4. Wait for installation to complete
5. Launch the application from Start Menu

### Mac - Using Self Service
1. Open Self Service from Applications
2. Browse or search for the application
3. Click "Install"
4. Enter your Mac password when prompted
5. Wait for installation to complete

## Common Software Installation Issues

### Installation Fails
1. Ensure you have administrator rights (check with IT)
2. Restart your computer and try again
3. Check if another version is already installed
4. Temporarily disable antivirus and retry
5. Check available disk space (need at least 2x the installer size)

### Application Won't Launch
1. Check if your system meets minimum requirements
2. Install any required updates or patches
3. Try running as administrator (right-click > Run as administrator)
4. Check Windows Event Viewer for error details
5. Reinstall the application

### License Activation Issues
1. Ensure you're connected to the company network
2. Check that the license server is accessible
3. Try activating manually:
   - Open the application
   - Go to Help > Activate
   - Enter your license key (from IT)
4. If still failing, contact IT for license server issues

## Specific Software Guides

### Microsoft Office
- Pre-installed on all company computers
- Sign in with your company email
- Activation is automatic via company license

### Visual Studio Code
1. Download from https://code.visualstudio.com
2. Run the installer
3. Install recommended extensions from company extension pack
4. Sign in with your company GitHub account

### Slack
1. Download from https://slack.com/downloads
2. Install and launch
3. Enter workspace URL: company.slack.com
4. Sign in with your company email

### Zoom
1. Download from https://zoom.us/download
2. Install the Zoom Client
3. Sign in with SSO using your company email
4. Company SSO domain: company.zoom.us

## Uninstalling Software

### Windows
1. Settings > Apps > Apps & Features
2. Find the application
3. Click "Uninstall"
4. Follow the uninstallation wizard

### Mac
1. Open Finder > Applications
2. Find the application
3. Drag to Trash (or use the app's uninstaller if provided)
4. Empty Trash

## When to Escalate
- Software request denied but business-critical
- License activation issues
- Software conflicts with existing applications
- Need admin rights for installation
- Custom or specialized software needed
- Security concerns about specific software
